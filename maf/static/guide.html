multiple-agents-flow

留在主對話，讓其他 Agent 接手小工作

MAF 讓你留在 Claude 或 Codex 的開發對話中。平常直接描述需求，主 Agent 會依 flow 處理委派、測試與進度；畫面只設定常用 flow。定義一次，就能在每個已有首個 commit 的 Git 專案使用。

設計理念

主對話保持短而清楚

Claude 或 Codex 處理日常開發與整合；路徑清楚、可單獨驗收的小工作，才交給 Pi 或 Antigravity。獨立任務最多可同時跑三個。

規畫由你決定

大型任務需要 Codex 規畫時，才手動輸入 /maf-plan。選到 planned flow 不會自動啟動規畫模型。

證據對準同一個 commit

MAF 在獨立 worktree 執行你指定的測試。審查可選：未勾選時結果是 tested；勾選且審查通過才是 verified。

少打擾，仍保留控制權

普通小任務在既定範圍內自動往下做；範圍敏感或需求不明時先請你核准一次，風險或權限問題才再次停下。發布與合併要另外授權。

三步開始

1

在電腦上安裝一次

需要 Python 3.11+、Git、Claude Code 或 Codex，以及所選 flow 使用的 agent CLI。工具只需下載與註冊一次。

git clone https://github.com/ian902792/multiple-agents-flow.git
cd multiple-agents-flow
python3 flow.py install-skills
python3 flow.py ui

install-skills 會回傳 Claude／Codex skill 路徑。重新開啟主對話後就能使用 MAF skill。

2

選擇全域預設

回到設定頁，選主對話、小任務工具與模型；需要獨立審查時再勾選並選審查 Agent，按「儲存並設為全域預設」。Claude 與 Codex 各有自己的全域預設，Agent 送出任務時會自動選自己的 flow；同時開啟兩個主對話也不會互相覆蓋。畫面的主模型欄位是偏好記錄；目前 session 仍需在所用 CLI／App 內切換。

3

確認訂閱後開始工作

先向供應商確認所選模型包含於現有訂閱、沒有額外付費用量。MAF 不會代你更改帳單設定；更換使用中的模型路由時要重新確認。

python3 flow.py confirm-billing --no-overage
python3 flow.py --main codex confirm-billing --no-overage
python3 flow.py --repo /path/to/project --main codex doctor

doctor 只檢查 CLI、登入與確認紀錄，不呼叫模型。檢查完成後，在主 Agent 的專案對話中直接描述要做的工作。

不同 flow 怎麼用？

Flow適合你可以對主 Agent 說
quick日常開發；小任務可交 Pi。「maf 改用 quick，請完成這項修改。」
quick-antigravity日常開發；小任務可交 Gemini 3.8 Flash High。「maf 改用 quick-antigravity；獨立的小工作可交給 Gemini。」
planned較大任務；你決定是否手動請 Codex 規畫。「maf 改用 planned。」需要 Codex 規畫時再由你輸入 /maf-plan 需求。
codex-piCodex 主導，Pi 執行明確小任務；Claude Opus 5.5 審查可選、預設關閉。在 Codex 對話說「maf 改用 codex-pi，請完成這項修改。」
自訂名稱把常用的角色／模型組合儲存於設定頁。「maf 改用我的 flow。」或「maf 改回全域預設。」

Claude 與 Codex 各自沿用其全域預設，之後不用逐案選 mode。同一專案的兩個主對話也分開記錄 mode；切換只影響該 Agent 的新任務，已開始的任務保留原模型。審查核取方塊是每個 flow 各自的設定。

一個日常例子

在 Codex 專案對話中直接說：

這個專案用 codex-pi。請補上 docs/install.md 的安裝範例，
只修改該檔；完成後執行適合的測試、整合變更並回報結果。

Codex 會依 flow 準備任務範圍、測試與必要的委派。你會收到結果狀態、測試、commit SHA 和需要你處理的阻塞。未勾選獨立審查時結果是 tested；勾選且通過審查才是 verified。兩者都不表示已 push 或合併。

三件互不依賴的小事，可在同一則需求中列出各自的檔案與驗收方式。MAF 最多同時執行三件；主 Agent 負責整合，並檢查整合後的新 commit。

指令與輸出：誰需要用？

平常直接描述需求即可。Claude 用 /maf，Codex 用 $maf skill；下面是你可能主動使用的少數指令，Agent 的工作指令與 Python CLI 放在進階區。

給人：可選的直接控制
指令何時使用你會看到
/maf status 或 $maf status想直接查看目前 flow 與進度任務階段、阻塞、下一步
/maf mode 名稱 或 $maf mode 名稱想手動切換單一專案的 flow；default 回到全域設定目前模式、角色與帳單確認狀態
/maf-plan 需求大型任務由你決定呼叫 Codex 規畫計畫與私有結果路徑，不自動執行
/model、/effort在 Claude 中切換目前對話模型與 effort；Codex 請用其模型選單或 CLI 設定目前 session 的新設定
給主 Agent：依需求自動執行的 MAF 指令

安裝 skill 後，Claude 或 Codex 會在需要時使用這些操作。你不用逐條輸入；範圍核准、發布與合併仍由你決定。下列以 Claude 的 /maf 寫法表示；Codex 使用 $maf。

指令用途主要輸出
/maf setup [名稱]檢查專案是否就緒；可選擇覆寫 flowdoctor 問題與待確認事項
/maf delegate 需求把明確小任務交所選 Agentrun ID、tested／verified 或阻塞
/maf verify 需求測試已提交的主 Agent 修改；依設定決定是否審查run ID、測試與可選審查結果
/maf handoff RUN_ID讀取完成任務的證據commit SHA、測試、可選 review
/maf approve RUN_ID你確認具體範圍後才放行更新後的 run 與 queued 狀態
/maf resume RUN_ID診斷並恢復中斷任務阻塞原因與新狀態
/maf run 需求明確使用獨立 coder 的批次任務run ID、階段與結果
/maf install補做一次全域 skill 註冊Claude／Codex skill 路徑
給維護者：Python CLI 參考

以下均以 python3 flow.py 開頭；專案指令在子命令前加 --repo /path/to/project。多數回傳 JSON；錯誤會非零結束。

子命令用途主要輸出
install-skills、ui全域註冊／開啟畫面skill 路徑／本機網址
flows、flow-save FILE列出／匯入命名 flowflow JSON
settings、settings default-flow NAME查詢／設定全域預設設定 JSON
settings herdr on|off切換 Herdr 觀察 pane設定 JSON
init、mode [NAME|default]可選專案政策／模式覆寫路徑／有效模式與角色
doctor、confirm-billing --no-overage唯讀檢查／記錄人工訂閱確認問題陣列／確認 JSON
plan --goal-file FILE只讀規畫建議與私有結果路徑
delegate TASK.json、verify TASK.json、submit TASK.json排入小任務／驗證／批次任務run ID 與狀態
approve RUN_ID、resume RUN_ID放行／恢復任務更新後的 run JSON
work --once --run-id ID執行指定任務；可重複 ID 並行各階段與完成結果
status [RUN_ID]、progress --json讀取狀態與證據run JSON／摘要
handoff RUN_ID讀取精確 commit 證據測試與可選 review JSON
publish RUN_ID、merge RUN_ID在授權下發布／合併；需開啟獨立審查PR URL／結果或阻塞
herdr在 Herdr pane 啟動 supervisorworkspace 與 pane ID

權限、模型與 Herdr

模型設定

Flow Studio 管理主對話偏好與 MAF 子任務角色，但不切換目前 session。Claude 在 terminal 用 /model、/effort；Codex 用自己的模型選單或 CLI 設定。新模型是否可用，以自己的 CLI 與訂閱為準。

遇到風險

一般任務持續執行；敏感範圍、權限、安全或需求衝突會停在 awaiting_approval 或 needs_human。已核准的範圍內測試與修復不逐步打擾你。

Antigravity

選用 Gemini 前先以 agy models 檢查模型清單，再核對訂閱。MAF 使用已登入帳號、CLI sandbox 與受限權限；測試由 MAF supervisor 執行。

Herdr

設定頁可啟用觀察 pane。接著在 Herdr pane 執行 python3 flow.py --repo /path/to/project herdr；Agent 工作時開 pane，完成後關閉。關閉整合時 MAF 仍能正常運作。

進階任務 JSON、測試指令格式與恢復方式見專案的 docs/CLI.md。請只在可信任的 repository 執行已核准的測試命令。
